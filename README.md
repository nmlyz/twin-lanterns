Twin Lanterns is a spot-the-difference game: two hand-drawn scenes side by side, find every hidden difference before the timer runs out. Three scenes — a lantern night market, a harbor at dusk, and a forest cabin — with 30 differences to find, hints, combos, and a score to chase.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and click the differences. No network access needed; everything runs from local files.
